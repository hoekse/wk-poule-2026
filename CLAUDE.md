# Repository Hoeksema Schilderwerken

Deze repository bevat twee losse projecten:

- `index.html` — de WK Poule 2026 (eigen Supabase-tabel `poule_data`).
- `narrowcasting/` — het narrowcasting-scherm van Hoeksema Schilderwerken.
  Lees **`narrowcasting/CLAUDE.md`** voordat je iets aan het scherm of de inhoud ervan doet.
  De inhoud van het scherm staat in Supabase (tabellen `narrowcasting_slides` en
  `narrowcasting_instellingen`) en wordt via SQL aangepast, niet via bestanden.

Vercel deployt branch `main` automatisch.
